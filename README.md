# Python Projects

This repository contains **two fully documented, shell-based Python projects**. Both systems are designed with clear, menu-driven interfaces and adhere to Object-Oriented Programming (OOP) principles.

***

## Project 1: Restaurant Management System

**File:** `QuestionOne_Management_System.py`

### Objective
To develop a complete, Python-based management system to streamline a restaurant's daily operations, covering all essential business functions.

### Functionalities
* **Menu Management (CRUD):** Fully operational methods to **C**reate, **R**ead (View), **U**pdate, and **D**elete menu items.
* **Order Handling:** Processes both **in-house dining** and **takeout** orders. It includes a critical check against inventory *before* finalizing an order.
* **Payment Processing:** Generates a detailed, **itemized bill** and calculates customer change accurately.
* **Inventory Management:** Tracks raw material stock and **automatically deducts** quantities as orders are confirmed.
* **Code Quality:** Features a robust class-based structure, clear user prompts, input validation, and comprehensive documentation.


### How to Run
1.  Open Python 3 in your terminal or IDE.
2.  Navigate to the folder containing `QuestionOne_Management_System.py`.
3.  Run the file using Python 3:
    ```bash
    python QuestionOne_Management_System.py
    ```
4.  Follow the main menu options to begin management operations.

## Project 2: Nkumba University Calculator

**File:** `QuestionTwo_Calculator.py`

### Objective
To create a versatile Python calculator that assists students with standard arithmetic and essential advanced mathematical functions.

### Functionalities
* **Basic Arithmetic:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
* **Additional Functions:** Includes Modulo (`%`), Exponentiation (`^`), and Square Root (`sqrt`).
* **Usability:** Provides a clear, conversational user interface for seamless calculation input and result display.
* **Error Handling:** Gracefully manages runtime issues like **division by zero** and **invalid input types**.
* **Code Structure:** Designed using Functional principles with clear methods and in-line comments.

| Feature | Assessment Marks |
| :--- | :--- |
| Basic arithmetic operations (+, −, ×, ÷) | 10 |
| Additional functions (%, √, ^) | 10 |
| User-friendly input/output interface | 10 |
| Error handling (divide by zero, invalid input) | 10 |
| Code structure & documentation | 10 |

### How to Run
1.  Open Python 3 in your terminal or IDE.
2.  Navigate to the folder containing `QuestionTwo_Calculator.py`.
3.  Run the file using Python 3:
    ```bash
    python QuestionTwo_Calculator.py
    ```
4.  Enter your calculations as prompted. Type `exit` to quit.
